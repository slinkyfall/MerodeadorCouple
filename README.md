# El Mapa del Merodeador

Regalo interactivo para An*, inspirado en el Mapa del Merodeador de Harry Potter. Proyecto personal, sin fines de lucro, no afiliado ni respaldado por Warner Bros. ni J.K. Rowling.

## Qué es

Una experiencia web de 3 fases:

1. **Activación** — el visitante debe escribir el hechizo correcto para desbloquear el mapa.
2. **Revelación** — el mapa cobra vida: corredores del castillo, huellas animadas de Kevin y Anabella que se encuentran en el centro, y la banda sonora de Hedwig's Theme.
3. **Pergamino** — un pergamino con un contador en vivo del tiempo juntos, fotos y una carta.

## Stack

- [Vite 5](https://vitejs.dev/) + [React 18](https://react.dev/)
- [Tailwind CSS v3](https://tailwindcss.com/)
- Fuentes: MedievalSharp · Cormorant Garamond · IM Fell English (Google Fonts)

## Desarrollo local

```bash
npm install
npm run dev
```

Abre `http://localhost:5173`.

> **Nota:** `public/assets/mapa-fondo.jpg` no está incluido en el repositorio. Agrega una imagen de alta resolución del Mapa del Merodeador con ese nombre para que la fase 2 se vea correctamente.
